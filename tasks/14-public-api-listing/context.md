# Context — 14 public-api-listing

## Зачем

Новые страницы листинга (спека: [`docs/projects-redesign.md`](../../docs/projects-redesign.md)
§2, §5) читают из публичного API: теги со счётчиками, витрины разделов, метаданные
категорий, фильтруемый и по-настоящему пагинируемый `/works` (инфинити-скролл),
слаг+title в тайле. Слой данных уже готов (задача 13).

## Что уже есть в репо

- **Публичные роуты** — `back/src/routes/public.ts` (172 строки): `/health`,
  `/categories`, `/categories/:cat`, `/categories/:cat/:sub`, `/works?offset&limit`,
  `/works/by-id/:id`, `/works/:cat/:sub/:work`. Роуты объявлены **от корня** (Caddy
  срезает `/api`). 404 — `{error:'not_found', resource, slug|id}`.
- **DTO** — `back/src/dto.ts`: `Tile { id, src, w, h, cat, sub, variants }` (`toTile:107`),
  `CategoryNav`/`SubcategoryNav`/`SubcategoryListing`/`WorksPage`/`WorkDetail*`.
  Контракт зеркалируется в `front/src/api/types.ts` и `admin/src/api/types.ts` —
  **менять синхронно все три** (фронтовые правки — минимальные типовые, UI-код фронта
  задач 17–19 не трогать).
- **Композиция запросов** — `back/src/queries.ts`: `resolveCover` (cover_image_id →
  первая картинка → null), `workTile` (работа **без картинок в листинг не попадает**),
  `allWorks`/`allTiles` — полный обход дерева в памяти.
- ⚠️ `GET /works` сейчас пагинирует **в памяти**: `allTiles()` целиком → `.slice()`
  (`public.ts:106-117`). Индексов по `sort_order` в БД нет (добавить при
  необходимости — допустимо миграцией `0003_*`; скорее всего на текущих объёмах
  хватит JOIN'а без новых индексов).
- **Счётчики**: единственный — `SubcategoryNav.work_count` = все работы подкатегории,
  **включая работы без картинок** (`public.ts:57`) — уже сейчас может расходиться
  с числом тайлов. Спека §5.2 меняет семантику на «видимые».
- **Строгие контрактные тесты** — `back/src/routes/public.test.ts`:
  `Object.keys(tile).sort()` на строках 77 и 221, пагинация `:212-228`. Любое поле
  в `Tile` их роняет — правятся вместе с dto.
- **Лимиты** — `parseLimit`/`parseOffset` (`public.ts:26-43`): дефолт 60, max 100.
- Тесты ходят в приложение без сети: `app.handle(new Request(...))`; фикстура —
  `seed(db)` (обновлена в задаче 13: содержит теги, витрину, меты категории).
