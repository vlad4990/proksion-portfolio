# Task — 12 deploy-hardening

**Слой:** инфра/финализация. **Методология:** без TDD; корректность = `verify.md` (прод-подобный
запуск + сквозной e2e). Спека: §2, §9, §10, §11.

## Цель
Сделать стек прод-готовым и задокументированным: безопасный, самовосстанавливающийся,
поднимается одним `docker compose` на VPS, проходит сквозной сценарий.

## Шаги

1. **Compose — здоровье и порядок** — выставить `depends_on: condition: service_healthy`
   (`caddy`←`back`,`minio`; `back`←`minio`), вычитать healthcheck'и, `restart: unless-stopped`,
   корректные volumes (`caddy_data`,`caddy_config`,`app_data`,`minio_data`).
2. **Секреты** — все секреты через `.env`/docker-секреты/volume; убедиться, что они не попадают
   в образ и не коммитятся (`.env` в `.gitignore`; `.env.example` без реальных значений).
3. **MinIO харднинг** — не публиковать порты наружу (ни 9000, ни консоль 9001); завести
   отдельные app-credentials для бэкенда (не root); public-read строго на `images/*`.
4. **Caddy/HTTPS** — прод `SITE_ADDRESS=домен` (авто-TLS); immutable-кэш на `/media/*` и
   хешированных ассетах админки; проверить персист сертификатов.
5. **rclone в проде** — задокументировать одноразовую настройку `rclone.conf` (`rclone authorize
   yandex`), монтирование секрета, переменные `BACKUP_*`.
6. **Документация** — добавить прод-деплой-гайд (напр. `docs/deploy.md`): требования, переменные,
   запуск, восстановление из облака. Обновить корневой `CLAUDE.md` (раздел Backend/Docker —
   бэкенд теперь реальный; сервис `front`→`caddy`; новые сервисы/volumes/переменные) и
   `front/CLAUDE.md` при необходимости. Зафиксировать изменения в памяти проекта.
7. **e2e-смоук** — прогнать сквозной сценарий (см. verify) на прод-подобном поднятии.

## Требования
- Не вводить новую функциональность; только надёжность/безопасность/доки.
- В рантайме ровно `caddy`+`back`+`minio`; контейнеров-сборщиков нет.
- Makefile-цели (`up`/`down`/`logs-*`) актуальны под новые сервисы.

## Deliverables
Прод-готовые `docker-compose.yml`/`Caddyfile`/Dockerfile, app-credentials MinIO, `docs/deploy.md`,
обновлённые `CLAUDE.md`(+ память). Сквозной сценарий проходит.
