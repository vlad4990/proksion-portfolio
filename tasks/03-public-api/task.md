# Task — 03 public-api

**Слой:** `/back`. **Методология:** **TDD** (`bun test`). Спека: §4, §5, §7, §3.

## Цель
Реализовать публичные read-эндпоинты с зафиксированными контрактами ответов и seed-данные.
После задачи фронт может рендерить листинг и деталь работы против реального API.

## Эндпоинты (роуты от корня; снаружи `/api/...`)
| Метод | Путь | Ответ |
|---|---|---|
| GET | `/health` | `ok` (уже есть) |
| GET | `/categories` | список категорий (+ подкатегории/счётчики) для навигации |
| GET | `/categories/:cat` | категория + её подкатегории |
| GET | `/categories/:cat/:sub` | подкатегория + работы (тайлы `{id,src,w,h}`) |
| GET | `/works` | все работы (пагинация), тайлы `{id,src,w,h}` |
| GET | `/works/:cat/:sub/:work` | полная работа: описание + `images[]` (варианты/форматы/`w/h`/`alt`/`lqip`) |

## Шаги (TDD — тесты первыми)

1. **media-url.ts** — чистая функция `mediaUrl(key_base, variant, ext)` → `/media/{key_base}/{variant}.{ext}`
   и хелпер, собирающий блок вариантов для картинки (`thumb`/`full` × `avif`/`webp`/`jpg`).
   Тесты first.
2. **DTO/сериализация** — функции `toTile(work+cover)`, `toWorkDetail(work+images)`,
   `toCategoryNav(...)`. Тесты: форма ответа точно соответствует контрактам §7.
3. **Роуты** (Elysia) поверх репозиториев задачи 02:
   - резолв `:cat/:sub/:work` слагов → 404 при отсутствии;
   - listing сортируется по `sort_order`;
   - `/works` — пагинация (зафиксируй: offset/limit или курсор; дефолт лимита ~60).
   Тесты first: 200 + форма, 404-кейсы, порядок, пагинация (границы).
4. **seed** — `bun run seed` (скрипт): несколько категорий → подкатегорий → работ → картинок
   (правдоподобные `key_base` + натуральные `w/h`, без реальных файлов). Идемпотентно
   (очистка/upsert). Используется и тестами как фикстуры (или отдельный fixtures-хелпер).

## Требования
- Контракты ответов — стабильные и задокументированы (в коде типами + кратко в комментарии).
  Фронт (09–10) на них завязан — менять потом дорого.
- Strict TS, без `any`. Ошибки → корректные статусы (404 для ненайденных слагов).
- Не обращаться к MinIO; `media-url` — чистая строковая сборка.

## Deliverables
Публичные эндпоинты + сериализаторы + `media-url` + seed-скрипт, всё под `bun test`.
`curl /api/categories/.../...` отдаёт ожидаемый JSON.
