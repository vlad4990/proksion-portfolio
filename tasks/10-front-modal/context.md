# Context — 10 front-modal

## Цель в одной строке
Полноэкранная модалка работы (описание + карусель картинок) с шарящимся URL, открываемая кликом
по тайлу, в обоих деревьях desktop+mobile.

## Опорные разделы спеки
- §4 (URL: `/projects/:cat/:sub/:work` + `?img=<imageId>`), §7 (контракт детали работы),
  §8 (модалка в обоих деревьях, `<picture>` avif/webp/jpg, LQIP).
- `front/CLAUDE.md`: тайлы со стабильным `id` — задел под клик→модалка; занавес-герой; роутинг
  на `react-router` через `App.tsx`.

## Что уже есть
- Листинг из API в обоих деревьях (задача 09). Эндпоинт детали `/api/works/:cat/:sub/:work`
  (задача 03) отдаёт описание + `images[]` (варианты/форматы/`w/h`/`alt`/`lqip`).

## Методология — SDD
- По спеке; проверка = `npm run build` + визуальный/функциональный чек-лист. Без тест-ферст.

## Поведение
- Тайл `onClick` → `navigate('/projects/:cat/:sub/:work')` → модалка **поверх листинга**.
- Прямой заход на URL работы открывает модалку поверх листинга (deep-link).
- `?img=<imageId>` — открыть конкретный слайд карусели (для «скинуть конкретную картинку»).
- Закрытие (`Esc` / клик по фону / кнопка) → `navigate` назад на `/projects/:cat/:sub`.
- Карусель: `<picture>` с `<source type=avif>`/`<source type=webp>` + `<img jpg>`; LQIP-фон на
  время загрузки full-картинки.

## Инварианты / ограничения
- **Двойное дерево**: модалка в `components/desktop/*` И `components/mobile/*`.
- Strict TS, без `any`; без новых зависимостей в `/front` (карусель — своя, лёгкая).
- Не нарушать занавес-герой и существующий роутинг; модалка — дополнительный роут поверх листинга.
- Бренд/токены — без новых hex; uppercase для display-заголовков.
