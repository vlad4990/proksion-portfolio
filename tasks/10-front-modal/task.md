# Task — 10 front-modal

**Слой:** `/front`. **Методология:** **SDD** (build + визуал, без тестов). Спека: §4, §7, §8 +
`front/CLAUDE.md`.

## Цель
Кликабельные тайлы открывают полноэкранную модалку работы с описанием и каруселью; URL отражает
открытую работу и конкретную картинку; deep-link работает; всё — в обоих деревьях.

## Шаги

1. **Роутинг** (`App.tsx`) — добавить `/projects/:cat/:sub/:work`. Рендерить листинг + модалку
   (модалка поверх). Поддержать `?img=<imageId>` (активный слайд). Прямой заход открывает модалку.
2. **Клик по тайлу** — в `ProjectsScreen.tsx` и `MobileProjects.tsx` повесить `onClick` →
   `navigate` на URL работы (сохранить текущий `:cat/:sub`).
3. **Данные** — загрузка `/api/works/:cat/:sub/:work` (описание + `images[]`). Состояние
   загрузки/ошибки/404 (несуществующая работа → редирект на листинг или 404-UX).
4. **Модалка (desktop)** — `components/desktop/`: полноэкранный оверлей, описание + карусель.
   Карусель: `<picture>` (avif/webp/jpg), LQIP-фон, навигация слайдов (стрелки/свайп-задел),
   синхронизация активного слайда с `?img=`. Закрытие по `Esc`/фону/кнопке → назад на листинг.
   Блокировка скролла фона на время показа.
5. **Модалка (mobile)** — `components/mobile/`: то же поведение, мобильная разметка (свайп
   карусели уместен). Единый контракт данных с десктопом.

## Требования
- Strict TS, без `any`; без новых npm-зависимостей в `/front`.
- Шарящийся URL: `/projects/:cat/:sub/:work` (+ опц. `?img=`) — копируется и открывает то же.
- Доступность: фокус-трэп в модалке, `Esc` закрывает, кнопка закрытия с aria-label.
- Не сломать занавес-герой и листинг (задача 09).

## Deliverables
Роуты работы в `App.tsx`, клик-навигация в обоих листингах, модалка с каруселью в обоих деревьях
(`<picture>` + LQIP), синхронизация `?img=`. `npm run build` зелёный; чек-лист пройден.
