# Task — 06 admin-api

**Слой:** `/back`. **Методология:** **TDD** (`bun test`; мутации с картинками — интеграция с
`minio`). Спека: §7, §3, §5, §6, §9.

## Цель
Полный набор защищённых admin-эндпоинтов для управления контентом, включая загрузку картинок
с обработкой и корректные каскадные удаления (БД + объекты S3).

## Шаги (TDD — тесты первыми)

1. **Категории / подкатегории** — `POST/PATCH/DELETE`. Create: слаг из title (уникальность в
   области), `sort_order` в конец. Тесты: создание + автослаг, правка, удаление (каскад в БД),
   доступ только с сессией+CSRF.
2. **Работы** — `POST/PATCH/DELETE /admin/works`. Поля: title, description, `subcategory_id`,
   `cover_image_id`, порядок. Создаётся без cover (проставляется после первой картинки).
   Тесты: CRUD, автослаг в области подкатегории, смена cover.
3. **Загрузка картинок** — `POST /admin/works/:id/images` (multipart). Прогнать через
   `images/store` (04) → залить варианты → создать строку `image` (key_base, w/h, lqip, alt,
   sort_order). Если у работы ещё нет cover — выставить эту картинку cover'ом. Тесты (интеграция):
   после загрузки есть строка `image` и варианты в MinIO; первая картинка стала cover.
4. **Картинки** — `PATCH /admin/images/:id` (alt, sort_order), `DELETE /admin/images/:id`
   (удалить строку + объекты S3 по key_base; если это cover — переназначить/NULL). Тесты:
   правка, удаление чистит и БД, и S3, cover корректно переуказан.
5. **Reorder** — `PATCH /admin/.../reorder` принимает упорядоченный список id → пишет
   `sort_order`. Для категорий/подкатегорий/работ/картинок. Тесты: порядок персистится.
6. **Хук мутаций** — обернуть успешные мутации вызовом `onMutation()` (стабильный no-op/эмиттер;
   задача 11 подменит реализацию). Тест: мутации триггерят хук.

## Требования
- Все роуты под guard (05) + CSRF; неавторизованный доступ → 401/403 (тесты обязательны).
- Strict TS, без `any`. Валидация входных данных (типы/обязательность) с понятными 4xx.
- Атомарность: при ошибке заливки в S3 не оставлять «висячую» строку `image` (и наоборот) —
  продумать порядок операций и откат.

## Deliverables
`routes/admin/*` (categories/subcategories/works/images/reorder) + хук `onMutation` + тесты.
`bun test` зелёный (с `minio` для интеграционных). Полный CRUD доступен с auth-cookie.
